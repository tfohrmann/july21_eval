# European July 2021 Flood -- Evaluation Code

This repository contains code to evaluate and visualize the simulation output for the paper "The influence of soil moisture on the extreme precipitation event in
July 2021 in Western Europe" (placeholder doi).

The contents are:
- analysis_tools.py: Functions for loading grid and model data 
- config.py: General setup
- tracking.ipynb: Notebook for preprocessing moisture tracking inputs
- visualizations.ipynb: Notebook for generating the figures in the publication
